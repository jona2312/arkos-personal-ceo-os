# Borrador — Prueba de ARKOS

> Carpeta de pruebas: `D:/ARKOS/ArkosTrial`

## Regla de cero pagos

Durante toda la prueba **no se gasta dinero**: sin suscripciones, sin créditos de API de pago, sin compras ni envíos de datos a servicios de terceros. Si una herramienta requiere pago, se deja registrada como pendiente y no se ejecuta.

## Qwen es solo un modelo de prueba reemplazable

El modelo actual del piloto es **Qwen** y funciona únicamente como modelo de prueba: es reemplazable por cualquier otro modelo sin cambiar el flujo, las herramientas ni la carpeta de trabajo.

## Tres pasos para probar ARKOS

1. **Inventario**: listar el contenido de la carpeta de pruebas y confirmar qué hay (archivos de texto y audio).
2. **Validación de capacidades**: probar lectura, escritura y manejo de archivos sin salir de la carpeta asignada.
3. **Decisión final**: consolidar los hallazgos, anotar pendientes y definir el próximo paso real.
